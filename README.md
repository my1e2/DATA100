# Statistics / Data Analysis Coursework Repository

This repository contains coursework, datasets, and supporting materials completed throughout a statistics and data analysis course using R.

---

## Overview

The repository includes:

* Problem sets
* Course datasets
* Statistical analysis exercises
* Supporting reference materials

Topics covered throughout the course include:

* Descriptive statistics
* Data analysis
* Probability
* Inferential statistics
* Data visualization
* Statistical modeling
